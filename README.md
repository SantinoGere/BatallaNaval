# BatallaEstelar
En un futuro cercano, las grandes potencias del mundo se disputan el control de las galaxias. Ya no se trata solo de destruir naves enemigas, sino de dominar espacios hostiles llenos de campos de asteroides, minas espaciales ocultas y recursos estratégicos.
Cada comandante debe desplegar su escuadrón con inteligencia, administrar sus municiones y aprovechar nuevas tecnologías de combate como bombas de plasma de área, sensores de detección y misiles láser de largo alcance.
Pero los espacios son traicioneros: campos de asteroides inesperadas pueden bloquear rutas, y minas espaciales ocultas pueden hacer perder valiosas naves.
El objetivo no es únicamente destruir el escuadrón rival, sino también demostrar estrategia, precisión y capacidad de adaptación frente a un entorno cambiante.
En este contexto nace la Batalla Estelar, una guerra táctica por la supremacía de las galaxias.
2. Reglas del Juego
• Cada jugador tiene un sector estelar de 10x10 donde coloca sus naves.
• Las naves pueden variar en tamaño (2, 3, 4, 5 coordenadas espaciales).
• Cada turno, el jugador elige una coordenada para atacar.
1. Tipos de disparos especiales:
   - Radar: revela si hay un barco en un área pequeña (3x3).
   - Bomba: afecta un área de 2x2.
   - Misil: dispara en línea recta horizontal o vertical.
2. Naves con habilidades: algunas naves pueden moverse una casilla por turno o repararse una vez.
3. Sistema de puntos y niveles: no solo gana quien hunda todas las naves, también se lleva puntaje por precisión, combos de aciertos y uso eficiente de disparos.
4. Eventos aleatorios en el sector estelar:
   - Tormentas que bloquean coordenadas espaciales.
   - Minas ocultas que dañan al jugador que dispare allí.
   - Bonos (munición extra, disparo gratis, etc.).
5. Historial de jugadas: cada jugador puede consultar en pantalla un registro de aciertos y fallos.
Controles
Menú principal
Flechas ↑ ↓ → para moverse por las opciones.
Enter para seleccionar.
Colocación de naves:
Flechas ↑ ↓ ← → para mover el barco.
Tecla R para rotar.
Tecla Enter para confirmar posición.
Juego en sector estelar:
Flechas ↑ ↓ ← → para moverse por las coordenadas espaciales.
Tecla Enter para disparar.
Tecla 1, 2, 3 para seleccionar disparo especial (Radar, Bomba, Misil).
Otros controles:
Tecla P para pausar.
Tecla H para ver historial de disparos.
Tecla Q para salir de la partida.
